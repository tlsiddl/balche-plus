# balche-plus

메시지 한 턴을 카드로 꾸며 이미지로 저장하는 마리나라 개인 확장.
[ai-frontend-ddini/balche](https://github.com/ai-frontend-ddini/balche)를 고친 버전이에요.

## 원본에서 바뀐 점

- **번역문 발췌**: 화면에 번역문 칸이 없어도(번역만 보기 등) 마리나라에 저장된 번역문을 불러와 발췌해요.
  번역문이 없거나, 번역한 뒤 원문을 다시 뽑았거나 고쳤으면 원문을 써요.
- **iOS·휴대폰 화면**
  - 입력칸을 눌러도 화면이 확대되지 않아요.
  - 노치·홈 바에 버튼이 가리지 않아요.
  - 키보드가 올라오면 창이 보이는 영역에 맞춰지고, 본문을 고칠 땐 아래 설정 칸이 접혀요.
  - 버튼·탭·스티커 손잡이를 손가락으로 누르기 쉽게 키웠어요. 탭은 한 줄로 옆으로 밀어서 넘겨요.
  - 저장하면 공유 시트가 떠서 '이미지 저장'으로 사진 앱에 바로 넣을 수 있어요.

## 설치

폴더째 확장 경로에 넣고 활성화.

## 텍스트 상자 템플릿 추가

스티커 탭 → 텍스트 상자 → **내 템플릿** 안의 **+ 템플릿 추가 (JSON)** 에서 `.json` 파일을 올리면 템플릿이 늘어나요.
올린 템플릿은 칸 모서리의 **×** 로 지울 수 있고, 최대 60개까지 넣을 수 있어요.

처음 설치하면 내 템플릿에 예시로 **민트 태그**가 하나 들어 있어요. 지워도 다시 생기지 않아요.
바로 써볼 수 있는 예시 파일은 [`examples/text-templates.json`](examples/text-templates.json)에 있어요. 이 파일을 그대로 올려보면 어떻게 추가되는지 볼 수 있어요.

파일 하나에 여러 개를 넣어도 되고, 여러 파일을 한 번에 올려도 돼요.

### 양식

```json
{
  "id": "mint-tag",
  "name": "민트 태그",
  "sample": "mint",
  "bg": "#cdeee2",
  "border": [1.5, "#8fd1b8"],
  "radius": 10,
  "color": "#2f6f58",
  "weight": 500,
  "italic": false,
  "pad": [0.3, 0.9],
  "shadow": [3, 4, "#f7c3d4"],
  "outline": [0.16, "#ffffff"],
  "font": "pretendard",
  "fs": 26
}
```

| 항목 | 뜻 | 값 | 없으면 |
|---|---|---|---|
| `id` | 내부 구분용 이름 (영문 소문자, 숫자, `-`, `_`) | 문자열 | 이름에서 자동 생성 |
| `name` | 목록에 보이는 이름 | 문자열, 20자까지 | "내 템플릿" |
| `sample` | 처음 붙일 때 들어가는 글자 | 문자열, 40자까지 | `name` |
| `bg` | 배경색 | 색 | 투명 |
| `border` | 테두리 `[두께, 색]` | 두께 0.5 ~ 12 | 없음 |
| `radius` | 모서리 둥글기 | 0 ~ 60 또는 `"pill"` | 0 |
| `color` | 글자색 | 색 | `#111111` |
| `weight` | 글자 굵기 | 100 ~ 900 | 500 |
| `italic` | 기울임 | `true` / `false` | `false` |
| `pad` | 안쪽 여백 `[위아래, 좌우]` (글자 크기의 배수) | 0 ~ 2, 0 ~ 3 | `[0.3, 0.9]` |
| `shadow` | 번지지 않는 그림자 `[가로, 세로, 색]` | -20 ~ 20 | 없음 |
| `outline` | 글자 바깥 테두리 `[두께, 색]` (스티커 글씨용, 글자 크기의 배수) | 0.02 ~ 0.5 | 없음 |
| `font` | 붙일 때 쓸 글꼴 (아래 글꼴 이름 중 하나) | 글꼴 이름 | `pretendard` |
| `fs` | 붙일 때 글자 크기 | 10 ~ 120 | 26 |

- **색**은 `#f8c9d4`, `#fff`, `rgb(255, 0, 0)`, `rgba(0, 0, 0, 0.5)`, `hsl(...)`, `red` 같은 일반 CSS 색만 받아요. 그 밖의 값이 들어간 항목은 무시돼요.
- 숫자가 범위를 벗어나면 가장 가까운 값으로 맞춰져요.
- `font`, `fs`는 처음 붙일 때의 값이에요. 붙인 뒤 **폰트 설정**에서 상자마다 바꿀 수 있고, 바꾼 뒤 **저장**을 누르면 그 설정이 템플릿에 저장돼요.
- 글꼴 이름: `pretendard`, `wanted`, `suit`, `suite`, `bookk`, `dandi`, `chosun`, `kbiz`, `dangam`, `galmuri`, `limgul`, `leferi`, `mona`, `monaemoji`, `system`
  (직접 올린 글꼴은 이름이 기기마다 달라서, 붙인 뒤 폰트 설정에서 골라 **저장**하는 쪽이 편해요)
- 같은 `id`를 다시 올리면 덮어써요.

### 여러 개를 한 파일에

```json
[
  { "name": "민트 태그", "bg": "#cdeee2", "color": "#2f6f58", "radius": 10 },
  { "name": "보라 알약", "bg": "#e4dcf6", "color": "#4a3f73", "radius": "pill", "weight": 700 }
]
```

`{ "templates": [ ... ] }` 모양이나 `{ "민트": { ... }, "보라": { ... } }` 모양도 돼요.
